# Release gates

## Gate A — Source integrity
Public source inventory resolved; payloads acquired; repository checksum checked where available; SHA-256 recorded.

## Gate B — Real measurement baseline
C-FV01 and C-FV07 executed without controlled perturbation.

## Gate C — Disagreement and perturbation series
C-FV02 classification resolved; C-FV03–C-FV06 executed with origin labels and immutable source references.

## Gate D — Deterministic reproduction
Each case has code commit, parameters, source/output hashes, environment record and reproduction result.

## Gate E — Institutional Evidence Pack
All seven cases assembled; sufficiency gate passed or limitations explicitly retained. No unsupported causal or operational-performance claims.
