# Gate A — Source Integrity Checklist

Gate A is complete only when all boxes can be supported by retained evidence.

- [x] Dataset DOI and version DOI recorded.
- [x] Associated publication recorded.
- [x] Dataset licence recorded separately from article licence.
- [x] Sensor modalities and published file contracts recorded.
- [x] Software-loop / sequential-index alignment semantics recorded.
- [ ] Figshare repository file inventory captured from the live dataset record.
- [ ] Selected payload files acquired from repository-provided URLs.
- [ ] Repository-provided checksums verified where available.
- [ ] Independent SHA-256 computed for every selected payload.
- [ ] MAT variable/shape contracts validated after acquisition.
- [ ] At least one index-aligned CW/FMCW/RF triplet passes provenance preflight.

Until the unchecked items are complete, C-FV01 remains BLOCKED_SOURCE_INTEGRITY and no real-measurement PASS/FAIL result may be published.
