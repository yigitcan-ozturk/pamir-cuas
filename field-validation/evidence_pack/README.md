# PAMIR-CUAS Field Validation Evidence Pack

This directory is the assembly point for evidence generated from the public real-world validation corpus.

A release candidate requires:
- C-FV01 through C-FV07 case summaries;
- immutable source provenance and SHA-256 manifest;
- Evidence Object per case;
- reproduction manifest per case;
- explicit separation of real measurements, derived analysis, and controlled perturbations;
- first-divergence and causal-claim boundaries;
- evidence-sufficiency result;
- independent reproduction status.

No PASS/FAIL is pre-populated. Results are generated only after verified source acquisition and execution.
